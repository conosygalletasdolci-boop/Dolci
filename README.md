# Dolci - Pedidos

Sitio web estático para recibir pedidos de clientes.

## Archivos

- `index.html` — interfaz completa.
- `style.css` — diseño responsive.
- `app.js` — catálogo, carrito, pedido, factura y WhatsApp.
- `images/` — imágenes del sitio.

## Publicar en GitHub Pages

1. Sube todos los archivos al repositorio.
2. Mantén `index.html`, `style.css`, `app.js` e `images/` en la raíz.
3. En GitHub entra a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Selecciona `main` y carpeta `/ (root)`.
6. Guarda.

## Importante

Esta versión es una aplicación frontend. El pedido queda guardado localmente en el navegador del cliente y el botón de WhatsApp abre el mensaje del pedido.

Para que los pedidos se registren automáticamente en una base de datos y lleguen a un panel administrativo se necesitará posteriormente un backend.
